# AnalyseVentes

Tableau de bord d'analyse de ventes : nettoyage des données, indicateurs clés
et graphiques, avec une interface web interactive.

## Stack

Python, pandas, matplotlib, Streamlit, Docker, pytest.

## Installation

```bash
pip install -r requirements.txt
```

## Utilisation

Lancer le tableau de bord :

```bash
streamlit run app.py
```

## Tests

```bash
pytest
```
